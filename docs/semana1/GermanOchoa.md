## El problema

> Red de Fidelización y Puntos Inter-Comercio Tokenizados 

## ¿Quién lo sufre?

> El problema afecta principalmente a los tenderos locales y a sus clientes, aunque también involucra a otros comercios y organizaciones que podrían participar en la red.   

## ¿Cómo se resuelve hoy y qué cuesta?

> Actualmente, los tenderos resuelven la fidelización mediante métodos informales o herramientas separadas. Algunos ofrecen descuentos directos, tarjetas físicas con sellos, promociones por volumen, regalos ocasionales o beneficios para clientes conocidos. Estos mecanismos son fáciles de iniciar, pero tienen limitaciones importantes. 

Las tarjetas físicas pueden perderse, alterarse o destruirse. Además, no permiten consolidar el comportamiento de un cliente entre diferentes comercios. Los descuentos manuales reducen el margen de ganancia y no siempre producen información sobre si el cliente volverá. Las promociones por mensajes de texto o redes sociales dependen de que el comerciante recuerde a quién comunicarlas y no ofrecen un sistema común para validar las recompensas. 

Otra alternativa es adquirir una aplicación o programa de fidelización propietario. Esta opción puede incluir registro de clientes, campañas y reportes, pero genera costos de implementación, mensualidad, soporte, capacitación y, en algunos casos, personalización. Para un tendero individual, el costo puede no justificarse si el volumen de ventas es reducido o si los clientes no utilizan la aplicación. 

## ¿Por qué creo que blockchain podría aportar?

> Blockchain podría aportar valor si la red necesita un registro común de emisión, transferencia y redención de puntos entre comercios independientes. Cada negocio podría tener intereses distintos: un tendero quiere controlar su presupuesto promocional, otro quiere atraer nuevos clientes y el administrador necesita garantizar que los puntos no se dupliquen ni se emitan por fuera de las reglas acordadas. 

Una base de datos tradicional administrada por un único operador también podría resolver parte del problema. Por eso, la justificación no debe ser “usar blockchain porque es innovadora”. La pregunta correcta es si la red requiere que diferentes participantes compartan un historial verificable sin depender completamente de una sola entidad.
