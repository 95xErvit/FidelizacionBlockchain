## Mis historias de usuario

> Entre 5 y 7 historias en formato "como [rol] quiero [acción] para [beneficio]", pensadas desde distintos roles o necesidades del producto que el equipo está diseñando. Si escribes menos de 7, borra las líneas que no uses (mínimo 5).

1. Como cliente quiero acumular puntos por mis compras en diferentes tiendas participantes para obtener beneficios de fidelización sin depender de un solo comercio. 
2.	Como cliente quiero redimir mis puntos en diferentes tiendas participantes para aprovecharlos donde realmente los necesite
3.	Como tendero quiero asignar puntos a mis clientes de acuerdo con reglas establecidas para incentivar la frecuencia de compra y fidelizar a mis clientes. 
4.	Como tendero quiero aceptar puntos generados por otros comercios participantes para ofrecer beneficios adicionales a mis clientes y atraer nuevos compradores. 
5.	Como tendero quiero consultar el historial de puntos emitidos y redimidos para llevar un control transparente de las operaciones de mi negocio. 
6.	Como administrador de la red quiero establecer reglas comunes para la emisión, transferencia, redención y vencimiento de puntos para garantizar un funcionamiento justo y controlado entre los comercios participantes. 
7.	Como cliente quiero consultar mi saldo e historial de puntos para conocer cuánto valor tengo disponible y cómo lo he utilizado.
