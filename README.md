# FidelizacionBlockchain

Red de fidelización y puntos inter-comercio tokenizados (piloto Stellar testnet).

## Requisitos
- Node.js 18+
- npm 9+

## Instalación
```bash
cd frontend
npm install
```

## Cómo correrlo
```bash
npm run dev
```

El front estará disponible en http://localhost:5173

> Nota: el proyecto opera sobre la red de prueba (testnet) de Stellar. Todas las cuentas y activos son de prueba.
